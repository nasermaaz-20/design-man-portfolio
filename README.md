# Design Man Portfolio

A premium creative portfolio website built with React, Vite, Tailwind CSS, GSAP, and Framer Motion. This project is designed to present a modern digital brand with a luxury dark aesthetic, motion-based storytelling, and a professional service-focused layout.

## Overview

This portfolio is tailored for a creative professional or digital studio, combining:

- Strong visual identity
- Animated hero and storytelling sections
- Featured project gallery
- Service overview and process explanation
- Testimonials and social proof
- Conversion-focused final call-to-action

The interface is built to feel premium, modern, and highly conversion-oriented for clients seeking design and digital services.

## Key Features

- Responsive and mobile-friendly interface
- Smooth scroll and interactive motion effects
- Premium dark theme with neon/glow accents

- Clean component-based architecture for easy customization

## Installation

### Prerequisites

- Node.js 18 or later
- npm

### Install dependencies

```bash
npm install
```

## Run the Project

### Development mode

```bash
npm run dev
```

### Production build

```bash
npm run build
```

### Preview production build

```bash
npm run preview
```

## Customization Guide

You can easily tailor the site by editing:

- Text and portfolio data inside `src/data/`
- Section content in `src/sections/`
- Theme and styling in `src/styles/globals.css`
- Components and UI in `src/components/`
